# 知屿前端设计实施记录

> 设计方向：知识岛屿 / 海图 / 沉积层 / 灯塔感。主色用于路径与行动，灯塔暖光只用于当前任务、提醒和完成反馈。

## 视觉决策

| 维度 | 决策 | 边界 |
| --- | --- | --- |
| 色彩 | 潮汐青 `#197b88`、深海墨 `#101c20`、灯塔暖光 `#d98d42`、雾面背景 `#eef4f3` | 不再使用旧品牌蓝作为主叙事；状态必须同时有文字或图标 |
| 字体 | 系统中文正文 + `ui-monospace` 数据/快捷键 | 标题使用紧凑字距，不引入远程字体依赖 |
| 圆角 | 6 / 9 / 14 / 20px | 普通列表以边框分层，阴影只给浮层、composer、modal |
| 图标 | Lucide 18px、统一线性语言 | emoji 仅保留在模板/正文内容，不作为核心操作图标 |
| 动效 | 120 / 180 / 360ms，进入、进行中、完成、失败 | reduced-motion 下即时切换；点击压下，不做全局上浮 |
| 签名元素 | “航线”语义：路径分组、来源编号、今日任务和复盘回跳 | 不额外绘制海浪装饰，避免主题化过度 |

## 验收路径

- 键盘：`Ctrl+K → 输入关键词 → ↑↓ → Enter` 可打开搜索或文档。
- 文档：空库 → 写第一篇 → 编辑 → 自动保存状态 → 返回列表。
- AI：进入空态 → 选择任务 → 设置默认可见 → 生成中显示阶段 → 停止/重试 → 来源预览。
- 训练：学习目标 → 今日训练 → 诊断题 → 掌握度更新 → 统计薄弱主题 → 搜索结果。
- 移动：切换“手机版” → 底栏保留文档/收集箱/AI/训练营 → 更多页承载低频入口。
- 主题：浅色、暗色均保持背景 / 内容 / 浮层三层亮度关系。
- 动效：`prefers-reduced-motion: reduce` 下不依赖动画完成任务。
