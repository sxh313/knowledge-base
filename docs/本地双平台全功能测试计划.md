# 本地双平台全功能测试计划

## 测试范围

以本地 Web 应用为唯一测试对象，分别使用桌面宽度 `1280×800` 和 Android 常用手机宽度 `390×844` 验证。Android 侧重点是手机版布局、触控入口、底部工具栏和窄屏内容可用性，不把 Windows 安装包混入本轮结果。

## 执行矩阵

| 模块 | 检查内容 | 通过标准 |
| --- | --- | --- |
| 首页/文档 | 导航、搜索、排序、新建入口、文档卡片 | 页面加载，按钮有名称，入口可用 |
| 收集箱 | 添加、筛选、整理入口 | 表单可操作，空态和列表均正常 |
| 编辑器 | Markdown/富文本、保存、历史、导出、AI/Agent 入口 | 编辑器加载，工具按钮可见，内容不溢出 |
| AI 问答 | 输入、发送、检索引用、复制、编辑、导出、联网模式 | 测试问题返回回答；成功后不显示残留错误 |
| Agent | 输入、附件入口、计划预览、复制、编辑、审批/取消/撤销 | 只读请求可完成；危险操作仍需确认 |
| 学习规划 | 目标配置、预览、自动排期、完成进度、提醒 | 计划可生成；课程内容和复习提示只读 |
| 复习/统计/标签 | 页面加载、主要筛选/操作入口 | 无控制台错误，核心按钮可见 |
| 设置 | AI 服务、模型列表、来源顺序、下拉、联网搜索、云同步、安全迁移、数据管理 | 下拉项完整；折叠和配置入口可用；密钥不写入代码 |
| Android 视口 | 底部导航、更多菜单、输入区、安全区、长内容滚动 | 底部工具栏始终显示，内容不被遮挡 |

## 已执行结果

- 8 个核心路由均可加载，控制台未发现错误。
- 桌面宽度通过首页、收集箱、AI 问答、复习教练、Agent、学习目标、统计、标签、设置巡检。
- Android 宽度通过手机版模式切换，确认底部导航包含文档、收集箱、AI 问答、Agent 模式和更多。
- AI 问答实测“请用一句话说明什么是 Agent”，成功返回带引用回答，底部没有“回答生成失败”。
- Agent 实测只读总结请求，成功生成任务进度；复制和编辑按钮均可点击，编辑内容会带回输入框。
- 学习规划实测生成预览；规划卡片中不再出现“写下你的答案”和反思输入框。
- 设置页实测联网搜索下拉，Tavily、open-webSearch、DuckDuckGo 三项均可见。
- 编辑器页面成功加载，保存、历史、导出、富文本/Markdown 等工具均可见。

## 修复项

- AI 问答成功完成后清理遗留错误状态；失败时保留真实错误原因，方便定位。
- Agent 消息增加复制和编辑后重新发送入口。
- 学习规划的课程原文、练习和复习提示改为只读，仅保留完成进度与计划配置。
- 联网搜索 API Key 支持用户从剪贴板主动填入，不在前端源码或安装包中内置密钥。
- Android 手机版底部导航持续固定显示，并为底部安全区和内容留白。
