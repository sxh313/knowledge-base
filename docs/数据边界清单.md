# 数据边界清单

> 目的：明确每个本地数据表的领域 owner、是否允许同步、删除语义和重建方式。

| 数据域 | Dexie 表 | Owner | 同步默认值 | 删除/重建语义 |
| --- | --- | --- | --- | --- |
| 文档 | `journals` | `db/repositories/journals` | 是 | 软删除 tombstone；正文索引可重建 |
| 文档派生索引 | `documentChunks`、`documentLinks` | `indexing/documents` | 否 | 从文档正文、标题和别名重建 |
| 文档附属 | `notes`、`attachments`、`journalVersions` | 文档域 | 是 | 记录级更新时间；附件 Blob 导出为 data URL |
| 分类与搜索 | `categories`、`savedSearches`、`propertyDefinitions` | 文档域 | 是 | 软删除；搜索结果不作为持久化事实 |
| 卡片与知识图谱 | `cards`、`graphNodes`、`graphEdges` | 学习/知识域 | 是 | 记录级合并；FSRS 字段由复习逻辑维护 |
| AI 对话 | `aiConversations` | AI 域 | 是 | 正文可选同步；API Key 不进入此表 |
| 应用设置 | `settings` | 设置域 | 否 | 设备本地；包含 AI Key、同步 Token |
| Agent | `agentSessions`、`agentMessages`、`agentRuns`、`agentAuditLogs`、`agentRunEvents`、`agentStates`、`agentExecutionReceipts`、`memoryItems` | Agent 域 | 否 | 运行状态只能通过 transition；审计不可静默覆盖 |
| 学习目标 | `learningGoals`、`learningTasks` | 学习规划域；读取入口 `db/repositories/learning` | 是 | 任务状态按更新时间合并；通过 `learning/taskModel` 投影统一统计口径 |
| zero2Review | `zero2ReviewSessions`、`zero2ReviewMessages`、`zero2Mastery`、`zero2ReviewPlans`、`zero2ReviewTasks`、`zero2ReviewAttempts`、`zero2LearningMemories` | zero2Review 域；任务读取入口 `db/repositories/learning` | 进度默认同步，问答正文可选 | 来源只允许 `zero2agent`；掌握度由有效证据更新；任务表保持隔离但复用统一状态投影 |
| 同步冲突 | `syncConflicts` | 同步域 | 否 | 本地人工解决后保留解决记录 |

## 约束

1. 页面不得直接写 Dexie；必须调用 store 或领域 repository。
2. 派生索引不得作为同步事实，导入/同步后必须可重建。
3. 所有跨设备删除必须保留 tombstone，避免旧设备复活数据。
4. API Key、GitHub Token、主密码和签名材料不得进入普通备份、同步数据或诊断记录。
5. Agent 写入必须经过计划、权限、预览、批准和事务执行；诊断只保存脱敏摘要。
