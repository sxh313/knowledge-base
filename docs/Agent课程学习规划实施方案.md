# Agent 课程学习规划实施方案

## 目标

将“学习目标”从重复的计时条目升级为可执行的 Agent 课程计划。用户创建“学习 Agent”目标后，应用按内置 `zero2Agent` 课程生成每日任务；每个任务都能看到学习主题、对应原文、练习动作和完成状态。

## 整体框架

```text
内置 zero2Agent 课程索引
        ↓
课程规划器（固定顺序 + 每日时长 + 截止日期）
        ↓
LearningGoal（目标与提醒偏好）
        ↓
LearningTask（每天：主题 / 原文 / 练习 / 状态）
        ↓
学习目标页、首页今日航线、桌面通知
```

### 1. 课程来源

只使用内置 `zero2agent-kb.json` 的 Agent 主课程模块：基础、LangGraph、Claude Code 与 OpenClaw。课程文档已有模块和顺序元数据，规划器按它们的既定顺序安排，不依赖模型猜测。

### 2. 自动拆分规则

- 每篇课程文档生成一个学习单元，包含阅读、练习和原文链接。
- 当前版本使用系统默认的每日 30 分钟节奏；课程、日期与任务内容均由规划器确定，不提供手动录入。
- 每天任务标题显示“第 N 天 · 模块 · 主题”。
- 每个单元附一项可执行练习：复述机制、给出应用场景或写出边界条件；完成后可勾选、跳过或顺延。
- 计划总进度由已完成任务数计算；用户仅可查看任务资料、练习与进度，并标记学习完成。

### 3. 每日推送

- 目标默认启用每日提醒，默认时间为 09:00，可在学习目标页调整并一键授权桌面通知。
- 应用运行时，到了提醒时间会对当天未完成任务发送一次桌面通知，同时在首页“今日航线”显示入口。
- 纯网页无法在浏览器和应用均关闭时可靠地推送；桌面版或打开应用后可以正常提醒。后续若接入系统后台服务，可扩展为离线推送。

### 4. 数据模型

- `LearningGoal` 新增：计划类型、总任务数、提醒开关与提醒时间。
- `LearningTask` 新增：学习摘要、练习提示、课程来源引用和任务序号。
- 字段均为非索引数据，现有本地数据可自然兼容；旧目标保持原有行为。

## 实施步骤

1. 新建课程规划器：读取内置课程索引，筛选并排序 Agent 主课程，产出带资料与练习的日计划。
2. 扩展学习目标与任务数据字段，并让历史 Agent 目标自动升级为“Agent 课程计划”。
3. 重构学习目标页：只读展示进度、今天任务、资料链接与练习；不提供手动输入、跳过、顺延或改期。
4. 在首页今日航线加入当天学习任务入口。
5. 新建提醒服务：应用打开时检查当天计划，在设定时间显示一次桌面提醒。
6. 为规划器与提醒判定添加测试，执行类型检查和生产构建。

## 验收标准

- 创建 Agent 课程计划后，不再生成只有标题的重复任务。
- 每个任务有主题、至少一份可定位的内置原文和一项练习。
- 可看见总进度与今天待完成任务；完成、跳过、顺延后状态正确保存。
- 已授权通知时，当天达到提醒时间只提示一次；暂停目标不提示。
- 不影响普通自定义学习目标和既有学习任务。
