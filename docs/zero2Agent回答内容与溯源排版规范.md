# zero2Agent 回答内容与溯源排版规范

版本：v1.0  
适用范围：AI 学习问答、zero2Agent 面试复习、原文溯源、Markdown 内容渲染  
设计依据：`frontend-design` skill

## 1. 设计目标

回答页面不是“模型输出文本框”，而是一个可阅读、可验证、可继续学习的知识界面。

每次回答必须同时解决四件事：

1. 用户先看懂结论。
2. 用户能快速扫描重点。
3. 用户能看清代码、表格和图片。
4. 用户点击引用后能在弹窗中看到对应原文位置。

推荐阅读顺序：

```text
结论 → 关键要点 → 详细解释 → 示例/代码 → 图片或表格 → 原文证据 → 下一步复习
```

## 2. 推荐回答结构

### 2.1 顶部摘要区

回答开始不要直接输出长段落，先给一个摘要块：

```text
结论
一句话回答用户的问题。

适用场景：说明什么时候使用。
核心判断：说明最关键的取舍。
```

样式建议：

- 标题：16px，700。
- 结论正文：16px，行高 1.7。
- 背景：淡蓝色 `#EEF3FF`。
- 左侧增加 3px 主色线。
- 摘要最多 3 行，完整内容放在下面。

### 2.2 关键要点区

使用 3～5 条短列表，不要把所有内容写成一段：

```markdown
### 关键要点

- 先说明核心机制。
- 再说明适用条件。
- 最后说明限制和风险。
```

每条建议控制在 1～2 行。超过 5 条时需要分组，不要继续堆列表。

### 2.3 详细解释区

详细解释使用清晰的小标题：

```markdown
## 工作原理
## 什么时候使用
## 和其他方案的区别
## 常见误区
```

建议：

- 二级标题：18px，700，顶部间距 28px。
- 三级标题：15px，700，顶部间距 20px。
- 正文：15px，行高 1.8。
- 单行不要超过约 80 个汉字宽度。
- 每段控制在 2～5 行。

## 3. 代码排版规范

### 3.1 代码必须可见、可读、可复制

代码块不能被普通正文样式覆盖。必须有：

- 语言标识，例如 `TypeScript`、`Python`、`JSON`。
- 复制按钮。
- 横向滚动，不强制换行破坏代码结构。
- 长代码块最大高度，支持内部滚动。
- 深色背景和高对比度文字。
- 移动端允许左右滑动。

推荐视觉：

```text
┌─ TypeScript                         复制 ─┐
│ const result = await retrieve(query);  │
│ return result.filter(Boolean);         │
└────────────────────────────────────────┘
```

建议样式：

- 代码字体：`12.5px`，行高 `1.65`。
- 字体：`ui-monospace, SFMono-Regular, Consolas, monospace`。
- 背景：浅色 `#182033`，深色 `#101522`。
- 代码工具栏高度：34px。
- 代码内容内边距：16px。
- 代码块圆角：10px。
- 代码块与正文之间间距：16px。

### 3.2 代码语言识别

模型输出必须使用 fenced code block：

````markdown
```typescript
const answer = await ask(question);
```
````

没有语言标识时显示“代码片段”，不要显示 undefined 或空标签。

### 3.3 代码说明顺序

代码块前说明“它解决什么问题”，代码块后说明“关键行做什么”。不要只给代码不解释。

## 4. 图片排版规范

### 4.1 图片必须可查看

Markdown 图片不能只显示 alt 文本。渲染器需要支持：

- 图片自适应容器宽度。
- 保持原始比例。
- 点击图片打开大图预览。
- 预览窗口支持关闭、缩放、左右切换。
- 图片加载失败显示 alt 文本和重试提示。
- 图片下方显示说明和来源。

推荐结构：

```text
[图片主体]
图 1：RAG 的召回、重排和生成流程
来源：zero2Agent 原文 / 第 3 章
```

建议样式：

- 图片最大宽度：`100%`。
- 正文阅读区图片最大高度：`560px`。
- 图片圆角：10px。
- 图片边框：1px `#E4E8F0`。
- 图注：12px，颜色 `#667085`。
- 点击图片时使用遮罩层，不跳离当前回答。

### 4.2 图片安全

- 只允许 `https`、应用内资源和明确允许的本地资源。
- 不执行图片 URL 中的脚本。
- 外部图片加载失败时不影响正文阅读。

## 5. 表格、引用和提示块

### 5.1 表格

表格适合比较，不适合承载长段落：

- 表头使用淡蓝背景。
- 单元格字号 13px。
- 移动端支持横向滚动。
- 长文本单元格允许换行。
- 数字列右对齐。

### 5.2 提示块

统一使用四种语义：

```text
结论：蓝色
注意：橙色
风险：红色
成功：绿色
```

不要使用过多不同颜色。颜色必须表达状态，而不是装饰。

## 6. 溯源交互规范

### 6.1 引用显示方式

回答正文中的引用使用 `[1]`、`[2]`，与回答底部来源列表一一对应。

底部标题建议从“参考来源”改成：

```text
回答依据 · 3 个原文片段
```

每条来源显示：

```text
[1] Agent 面试通关
章节：RAG → 混合检索
原文摘要：……
查看原文位置
```

### 6.2 点击后弹窗，而不是直接离开页面

点击“查看原文位置”后打开来源弹窗：

```text
┌────────────────────────────────────────────┐
│ 原文证据                              ×     │
│ Agent 面试通关                              │
│ RAG → 混合检索                               │
├────────────────────────────────────────────┤
│                                             │
│ 被引用的原文片段                            │
│ 这里高亮显示实际命中的内容……                │
│                                             │
├────────────────────────────────────────────┤
│ [复制片段] [打开原文网页] [在来源页查看]      │
└────────────────────────────────────────────┘
```

弹窗要求：

- 桌面端宽度 `min(760px, calc(100vw - 32px))`。
- 移动端使用底部抽屉，高度不超过 `88vh`。
- 点击遮罩关闭。
- `Esc` 关闭。
- 关闭后保留原来的滚动位置。
- 弹窗打开时焦点进入标题或关闭按钮。
- 原文片段使用淡黄色 `#FFF0C2` 高亮。
- 显示章节路径、文件路径和 chunk 编号。

### 6.3 来源弹窗中的按钮命名

使用用户能理解的动作：

- `查看原文位置`
- `复制片段`
- `打开网页原文`
- `关闭`

不要使用：

- `Navigate`
- `Open chunk`
- `定位 Citation`

## 7. zero2Agent 严格回答格式

zero2Agent 必须使用严格模式：

```markdown
### 结论
只能依据课程原文给出总结。

### 关键要点
- 要点一 [1]
- 要点二 [1][2]

### 详细解释
按照章节顺序解释原文内容。

### 示例
```typescript
// 代码示例
```

### 注意
原文没有覆盖的内容必须明确说明，不允许使用模型常识补齐。

### 回答依据
[1] 章节名称 · 查看原文位置
[2] 章节名称 · 查看原文位置
```

如果没有可靠来源，回答固定为：

```text
所选 zero2Agent 知识库中没有找到足够的原文依据，暂时不能给出确定答案。
```

## 8. 普通 AI 与复习 AI 的区分

### 普通 AI

- 可以使用个人文档或混合知识库。
- 可以显示“常识补充”和“模型推断”。
- 来源区分个人文档、zero2Agent 和联网来源。

### zero2Agent 复习

- 只显示 zero2Agent 来源。
- 不允许联网来源混入。
- 不允许模型常识冒充课程原文。
- 回答后默认显示一道诊断题。
- 诊断题和来源区分为两个独立区域。

## 9. 移动端排版

- 正文不小于 14px。
- 代码块横向滚动，不自动压缩到不可读。
- 来源列表每项最小点击区域 44px。
- 溯源弹窗改为底部抽屉。
- 图片点击后使用全屏预览。
- 表格使用横向滚动容器。
- 回答底部来源区域和诊断题之间保留 20px 间距。

## 10. 推荐组件拆分

建议新增或扩展以下组件：

```text
AnswerRenderer
├── AnswerSummary
├── AnswerSection
├── CodeBlock
├── ImagePreview
├── TableRenderer
├── CalloutBlock
├── InlineCitation
├── CitationList
└── SourcePreviewModal
```

现有 `MarkdownContent` 负责 Markdown 基础渲染，`CitationList` 负责引用列表；建议新增 `SourcePreviewModal`，并让 `CitationList` 点击后打开弹窗，而不是默认跳转到独立来源页。

## 11. 验收清单

- [ ] 回答第一屏能看到明确结论。
- [ ] 长回答有二级标题和段落间距。
- [ ] 代码语言、复制按钮、滚动和字体清晰。
- [ ] 图片可以点击放大查看。
- [ ] 图片加载失败有可理解的错误提示。
- [ ] `[1]` 可以打开对应来源弹窗。
- [ ] 弹窗显示正确章节和命中片段。
- [ ] 弹窗支持关闭、Esc 和移动端底部抽屉。
- [ ] 来源只包含本次检索结果。
- [ ] zero2Agent 没有来源时不会生成确定性答案。
- [ ] 桌面端和 390px 移动端均无横向页面溢出。
- [ ] 深色模式下代码、引用和图片边界仍清晰。
