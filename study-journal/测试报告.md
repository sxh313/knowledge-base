## 二、发现并修复的 Bug

### Bug #1 【严重】FSRS 间隔重复算法 — 复习间隔计算错误

**文件**: `src/lib/algorithms/fsrs.ts`

**问题**: 原代码计算复习间隔的公式数学等价于 `stability²`（稳定性平方），导致复习间隔被严重夸大。例如稳定性 = 3 天时，计算出 9 天后才复习，正确应为 3 天。

**根因分析**:
```
原公式: interval = log(0.9) / log(0.9^(1/S)) * S
数学化简: = log(0.9) / ((1/S) * log(0.9)) * S
         = S²     ← 错误！应该是 S
```

**修复**: 根据FSRS遗忘曲线模型 `R(t) = (1 + t/(9·S))^(-1)`，在目标保持率 90% 时，最优间隔天数 = 稳定性 S。

```typescript
// 修复前
const retention = Math.pow(0.9, 1 / stability);
const interval = Math.max(1, Math.round(Math.log(0.9) / Math.log(retention) * stability));

// 修复后
const interval = Math.max(1, Math.round(stability));
```

**影响**: 此 bug 会导致所有知识卡片的复习间隔严重失真，直接影响用户体验。

### Bug #2 【中等】日记编辑器自动保存 — 仅新日记生效

**文件**: `src/pages/JournalEditor.tsx`

**问题**: 自动保存逻辑仅在 `isNew === true` 时触发，编辑已有日记时修改内容不会自动保存，只有手动点击"保存"按钮才行。

**修复**:
- 移除 `isNew` 限制条件
- 将依赖数组从仅 `[content]` 扩展为 `[title, content, subject, tagsInput, timeSpent, difficulty]`
- 防抖时间从 5s 缩短为 3s（更好的用户体验）

---

### Bug #3 【轻微】AIChat 页面 — ref 绑定到两个元素

**文件**: `src/pages/AIChat.tsx`

**问题**: `messagesEndRef` 同时绑定到消息容器 `<div>`（第81行）和底部哨兵 `<div>`（第115行）。React 会将 ref 指向最后一个元素，导致容器上的 ref 无效。

**修复**: 新增独立的 `scrollContainerRef` 用于容器，`messagesEndRef` 专用于底部滚动定位。
